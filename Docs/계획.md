# TwinSwift 계획

작성 2026-10-13. 1차(SProject) 세션에서 정한 내용.

## 1. 목표
- 취업용 포트폴리오 (언리얼 클라이언트 프로그래머)
- 4~5주 안에 완성하고 지원 시작
- 이야기: "1차를 측정해 한계를 찾고 → 2차에서 구조부터 재설계 → 숫자로 개선 확인"

## 2. 컨셉
**두 캐릭터(전사·마법사)를 실시간으로 바꿔 가며 싸우는 3D 태그 액션 보스 러시**

| 항목 | 결정 |
|---|---|
| 구조 | 보스 러시: 보스 3마리, 보스 사이에 강화 선택 |
| 핵심 | 태그. 모든 보스가 교체를 잘해야 이기게 |
| 시점 | **미정**: 쿼터뷰(추천) vs 높고 넓은 3인칭+락온. 조각 1에서 둘 다 붙여 보고 확정 |
| 체력 | **미정**: 각자(추천) vs 공유 |
| 배경 | **미정** |
| 부위 파괴 | **미정**: 넣으면 3인칭+락온, 보스 수 축소 |

### 태그 규칙
- **스킬 입력 = 교체**: 상대 캐릭터 스킬을 누르면 교체하며 바로 시전 (메이플 제로 방식)
- **교체 어시스트**: 나가는 캐릭터가 한 방 남김
- **타이밍 교체**: 맞기 직전 교체하면 회피 + 짧은 슬로 모션
- **확정 표식**: 확률이 아니라 특정 스킬이 표식을 걸고, 다른 캐릭터가 터뜨림

### 보스 3마리 = 태그 교육 과정
| 보스 | 시험하는 것 |
|---|---|
| 1 | 시너지 (표식 → 교체 → 폭발) |
| 2 | 타이밍 교체 (연속 공격을 교체로 회피·반격) |
| 3 | 교체 패턴 읽기 (플레이어의 교체 습관을 학습해 노림) |

## 3. 기술 방침
- 엔진 UE 5.7. 하드웨어 레이트레이싱·Substrate·가상 그림자맵 끔, Scalable 시작. Lumen은 측정 후 결정
- 에셋: 믹사모 (전사·마법사 같은 뼈대). Paragon 사용 안 함
- 태그 구조: **캐릭터 하나에 몸(메시) 둘 = 상주형**. 교체를 GAS 능력으로 만들어 클라 예측 실행. Possess·InitAbilityActorInfo 반복 없음
- 네트워크: 콘텐츠는 싱글, 코드는 처음부터 서버 권한. 마지막에 2인·500ms 검증 영상
- 조준: `GetAimPoint()`로 분리 → 시점을 바꿔도 스킬 코드 그대로
- 카메라 설정은 데이터 에셋 하나로
- 애니메이션 연결: `OnBlendOut` 종료, 입력 버퍼, 캔슬 윈도우, 서 있으면 전신·움직이면 상체
- 애님 로직은 C++ AnimInstance에서 계산, 그래프는 연결만
- 데미지: SetByCaller 계수 (스킬마다 배율)

## 4. 조각 순서
각 조각: 작성 → 빌드 → 확인 → 기록 → 다음

| # | 조각 | 1차에서 가져올 것 | 확인 |
|---|---|---|---|
| 0 | 프로젝트 설정 | Build.cs, 플러그인, 렌더링 설정, LFS, CoreRedirects | 빈 맵 실행 |
| 1 | 캐릭터 이동 + 카메라 | 컨트롤러 입력 일부, `CharacterAnimInstance` | 믹사모 캐릭터 걷기·달리기, 시점 2개 비교 → 확정 |
| 2 | GAS 기반 | `SPlayerState`(ASC 소유), `SAbilitySystemComponent`, `SAttributeSet`, 태그 | `showdebug abilitysystem`에 체력·마나 |
| 3 | 기본 공격 1개 | `GA_AttackBase`, `AN_SendTargetGroup`, `SDamageExecution`, 데미지 GE | 허수아비에 데미지 숫자 |
| 4 | 능력 베이스 정리 | `SGameplayAbility` + BlendOut 종료 + 입력 버퍼 | 콤보가 끊기지 않음 (Rewind Debugger) |
| 5 | 태그 교체 (상주형) | 새로 작성 | 교체 즉시, 체력·쿨다운 유지 |
| 6 | 회피 + 타이밍 교체 | `GA_Dodge` (무적) | 맞기 직전 교체 → 회피 + 슬로 |
| 7 | 스킬 이식 | 전사 → 마법사 하나씩 | 스킬마다 동작 |
| 8 | 표식·시너지 | `ExecuteSynergyLogic` (확정 방식으로) | 표식 → 교체 → 폭발 |
| 9 | 보스 1 | AI 컨트롤러, BT | 처음부터 끝까지 클리어 |
| 10 | 보스 2·3, 강화 선택 | | 전체 런 |
| 11 | 측정·멀티 검증·영상·README | | 지원 가능한 저장소 |

### 가져오지 않음 (1차 저장소에 남김, README에서 링크)
