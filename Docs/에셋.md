# 외부 에셋

라이선스 때문에 원본 에셋은 저장소에 올리지 않음 (`.gitignore`).
프로젝트를 열려면 아래 에셋을 받아 같은 경로에 넣어야 함. 코드·몽타주·애님 블루프린트·칼 메시는 저장소에 있음.

| 에셋 | 받는 곳 | 넣는 경로 | 쓰는 것 |
|---|---|---|---|
| Knight Free (저폴리 기사) | 외부 무료 에셋 | `Content/Asset/Knight_Free/FBX`, `Texture` | 기사 메시·스켈레톤·텍스처 |
| 믹사모 대검 애니 (Great Sword …) | Mixamo | `Content/Asset/Knight_Free/Animations` (`Tools/import_knight_anims.py`) | 이동·공격 애니 |
| SwordTrailVFX | Fab | `Content/SwordTrailVFX` | 칼날 궤적 `NS_Trail_16` |
| Knife_light | Fab | `Content/Knife_light` | 반달 베기 `NE_attack02`, `NE_attack05` |

에셋을 넣은 뒤 다시 맞추는 스크립트: `setup_weapon.py` → `setup_blade_sockets.py` → `make_in_place.py` → `setup_combo.py` → `setup_slash_fx.py` → `setup_trail_notify.py`
